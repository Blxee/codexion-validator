# Codexion Validator

Is an automatic evaluator (moulinette) for codexion binaries.

## Features:

As of now, this moulinette tests:

* **Parsing** thoroughly
* **Behaviour** still improving

## Installation:

- Go to the [releases page](https://github.com/Blxee/codexion-validator/releases), and download the latest release binary for your architecture.
- Once `codexion-validator` is downloaded, you need to add the **excutable** permission using the following command:

```bash
chmod +x codexion-validator
```

## Running the moulinette:

To run it basically provide the path to the **codexion binary** as a first argument:

```bash
./codexion-validator codexion
```

this project is still in development and may not be complete in some aspects.
